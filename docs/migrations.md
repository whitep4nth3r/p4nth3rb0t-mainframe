# Database Migrations

## Generate a New Migration

To generate a new migration, use the following command:

```bash
npm run generate-migration --name=MigrationName
```

Replace `MigrationName` with the desired name for your migration.

### Run Migrations

To run all pending migrations, use the following command:

```bash
npm run run-migrations
```

### Revert the Last Migration

To revert the last executed migration, use the following command:

```bash
npm run revert-migration
```
